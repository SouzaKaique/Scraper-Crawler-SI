In [3]:
HEADLESS = False
PAGES = 10
BASE_URL = 'https://books.toscrape.com/catalogue/'

def web_driver():
    options = webdriver.ChromeOptions()
    if HEADLESS:
        options.add_argument('--headless=new')
    return webdriver.Chrome(options=options)

def get_soup(driver):
    return BeautifulSoup(driver.page_source, 'html.parser')

2. Coleta do catálogo (paginação)¶

Cada página do catálogo tem 20 livros. O BeautifulSoup extrai título, link, preço e avaliação (estrelas) de cada um; depois o Selenium clica no botão next e espera o indicador "Page X of 50" mudar antes de ler a próxima página.

In [4]:
driver = web_driver()
driver.get(BASE_URL + 'page-1.html')

books = []
for page in range(1, PAGES + 1):
    soup = get_soup(driver)
    for article in soup.select('article.product_pod'):
        books.append({
            'titulo': article.h3.a['title'],
            'link': BASE_URL + article.h3.a['href'],
            'preco': article.select_one('.price_color').text,
            'avaliacao': article.select_one('.star-rating')['class'][1],
        })
    if page < PAGES:
        driver.find_element(By.CSS_SELECTOR, 'li.next a').click()
        WebDriverWait(driver, 10).until(
            EC.text_to_be_present_in_element((By.CSS_SELECTOR, 'li.current'), f'Page {page + 1} of'))

3. Crawling das páginas dos livros¶

O Selenium abre o link de cada livro; da página de detalhe extraímos a categoria (no caminho Home > Books > Categoria), o estoque disponível e o código UPC (identificador único do livro).

In [6]:
for book in books:
    driver.get(book['link'])
    soup = get_soup(driver)
    info = {row.th.text: row.td.text for row in soup.select('table.table tr')}
    book['categoria'] = soup.select('ul.breadcrumb a')[-1].text
    book['estoque'] = info['Availability']
    book['upc'] = info['UPC']

4. Tratamento dos dados¶

  • remoção de duplicados (pelo UPC) e de linhas incompletas;
  • preço £51.77 → 51.77 (float);
  • avaliação Three → 3 (int);
  • estoque In stock (22 available) → 22 (int);
  • as categorias genéricas do site (Default e Add a comment) viram Sem categoria.
In [7]:
RATINGS = {'One': 1, 'Two': 2, 'Three': 3, 'Four': 4, 'Five': 5}

df = pd.DataFrame(books).drop_duplicates('upc').dropna()
df['titulo'] = df['titulo'].str.strip()
df['preco'] = df['preco'].str.replace(r'[^\d.]', '', regex=True).astype(float)
df['avaliacao'] = df['avaliacao'].map(RATINGS)
df['estoque'] = df['estoque'].str.extract(r'(\d+)')[0].astype(int)
df['categoria'] = df['categoria'].replace({'Default': 'Sem categoria', 'Add a comment': 'Sem categoria'})

6. Conclusões¶

  • Coleta: 10 páginas do catálogo percorridas com o botão next, 200 livros coletados e 200 páginas de detalhe visitadas, sem duplicados nem valores faltantes após o tratamento.
  • Categorias: 35 categorias; Sequential Art (23 livros) e Nonfiction (20) são as maiores. 38 livros estão em categorias genéricas do site (Default / Add a comment), agrupadas como Sem categoria.
  • Preços: de £10,16 a £59,64, com média de £34,80, espalhados de forma quase uniforme por toda a faixa.
  • Avaliações: 1 estrela é a nota mais comum (49 livros). O preço não acompanha a nota: o preço médio por nota fica entre £33,74 e £36,19 e a correlação entre preço e avaliação é praticamente zero (0,02).
  • Destaque: entre as categorias com pelo menos 5 livros, Fiction tem a melhor nota média (3,9 estrelas) e também um dos maiores preços médios (£43,05).
  • Estoque: entre 15 e 22 unidades por livro, 78% deles com 15 ou 16; o estoque também não depende do preço (correlação de 0,07).

Como o site é fictício e seus dados foram gerados para prática, a ausência de relação entre preço, avaliação e estoque é esperada: o valor do projeto está no processo de coleta (paginação + crawling), tratamento e análise.
